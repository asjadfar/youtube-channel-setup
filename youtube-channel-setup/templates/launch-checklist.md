# Launch Checklist

Complete every item, then stop for the approval gate. Nothing goes live until the owner approves the exact name, handle, description, branding, settings and links.

## Brief

- [ ] Brief filled in (`templates/channel-setup-brief.md`)
- [ ] Brief confirmed by the owner — date: ____
- [ ] Tier agreed: [ ] Basic $80 / [ ] Standard $180 / [ ] Premium $350

## Account and locale

- [ ] Google account chosen (owner's account — no password or code recorded anywhere)
- [ ] Owner signed in to YouTube on their own device
- [ ] Country set in YouTube Studio > Settings > Channel > Basic info
- [ ] Language set
- [ ] Channel verified with the owner's phone number (unlocks custom thumbnails, longer videos, live streaming)

## Name and handle

- [ ] Channel name chosen — final name:
- [ ] Handle availability checked live in YouTube Studio
- [ ] Final handle: @
- [ ] Name and handle are consistent everywhere the channel is mentioned (website, Fiverr gig, social accounts)

## Description

- [ ] Description written from `templates/channel-description.md`
- [ ] First two lines say who the channel is for and what viewers learn
- [ ] Upload rhythm written only if the owner can keep it
- [ ] No promises about views, subscribers or earnings
- [ ] Owner approved the exact description text — date: ____

## Branding

- [ ] Profile picture made to spec (800 x 800 minimum, square, reads at 98 x 98)
- [ ] Banner made to spec (2560 x 1440)
- [ ] Banner checked with `scripts/banner_safe_area.py` — all text inside the safe area
- [ ] Profile picture and banner show the same characters
- [ ] Owner approved both images at full size and at small size — date: ____

## Settings

- [ ] Default upload settings set (title pattern, description footer, tags, category, language)
- [ ] Made-for-kids setting chosen and recorded — [ ] Yes / [ ] No / [ ] Review per video
- [ ] Feature eligibility confirmed (verified channel)
- [ ] Links added — only links the owner approved, every link checked on desktop and mobile

## Approval gate — owner signs off before launch

- [ ] Channel name and handle approved — date: ____
- [ ] Description approved — date: ____
- [ ] Profile picture and banner approved — date: ____
- [ ] Settings and links approved — date: ____

## Launch (on the owner's device)

- [ ] Channel created (owner clicks "Create channel", enters approved name and handle)
- [ ] Approved description pasted
- [ ] Approved profile picture and banner uploaded
- [ ] Approved settings and links applied
- [ ] Channel checked live in a signed-out browser: name, handle, description, profile picture, banner (desktop strip and mobile), links
- [ ] Channel checked live on a phone
- [ ] First video plan ready (title, topic, who makes it)

## After launch

- [ ] Live channel URL returned to the owner:
- [ ] First-week daily checks done (banner, links, first video published on plan)
- [ ] Delivery record: channel URL, handle, description, branding files, settings, first video plan
