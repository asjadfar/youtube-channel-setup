# Channel Description Template

The description answers three questions in the first two lines — YouTube shows only the first two lines before "more":

1. Who is this channel for?
2. What will viewers learn or get?
3. How often do videos come out?

Keep it short: one paragraph plus one line of links or contact. No keyword stuffing, no copied text from another channel, no promises about views, subscribers or earnings. The owner approves the exact text before it is pasted into YouTube Studio.

## Template

```
Welcome to [Channel Name]!

[Channel Name] is a [type of channel] for [audience, ages if a kids' channel].
Every video teaches [learning topics — for example sounds, animals, colors, numbers, letters] through [how — for example friendly songs, stories and games].

New videos [upload rhythm — for example every Tuesday and Friday].

[Optional: one line about the host character — for example "Join [Host] and friends on every adventure!"]

[Links — only links the owner approved, for example website / Fiverr gig]
```

## Worked example (template example — adapt it, do not copy it blindly)

The example below follows the Bunny Sounds pattern: a kids' learning channel where every video teaches something, with one host character and the same friends in every episode.

```
Welcome to Bunny Sounds!

Bunny Sounds is a learning channel for toddlers and preschoolers.
Every video teaches something new — animal sounds, colors, numbers and letters — through friendly songs and stories with Bunny and friends.

New videos every week.

Join Bunny and friends — Cow, Lion, Elephant, Dog, Duck and Pig — on every adventure!
```

## Checklist before pasting it into YouTube Studio

- [ ] First two lines say who the channel is for and what viewers learn
- [ ] Learning topics are named (not just "fun videos")
- [ ] Upload rhythm is written only if the owner can keep it
- [ ] No promises about views, subscribers or earnings
- [ ] No text copied from another channel
- [ ] Links are only the ones the owner approved, and each one opens the right page
